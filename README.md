# Savor & Sweet

A responsive restaurant and bakery website.

## About
Savor & Sweet is a simple website showcasing
delicious food, freshly baked cakes, pastries,
and bakery products.

## Features
- Responsive website design
- Food and bakery product showcase
- Image carousel
- Clean and user-friendly interface

## Technologies Used
- HTML5
- CSS3
